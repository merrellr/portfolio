Under the hood How this page works
  • Every colour, font and corner radius on the site is a CSS custom property. Each style or accent is a small set of overrides on the <html> element, in light and dark versions.
  • A short script in the page head reads your choices before anything is drawn, so a returning visitor never sees the default look flash first.
  • Text size scales from one root value, because every font size is set in rem.
  • Your choices are kept in this browser's local storage. Nothing is sent to a server. If storage is blocked, the site still works and simply forgets on the next visit.
  • No frameworks and no build step: plain HTML, CSS and JavaScript. Read the code ↗
